# Soil Hyperspectral Deep Learning Literature Library

本目录用于建立土壤高光谱与深度学习方向的文献研究库，服务于未来一周的集中调研。

当前阶段的目标不是开发模型，而是系统梳理研究脉络、典型数据集、主流方法、评价指标、关键论文和可复现方向，为后续模型设计提供依据。

## 研究范围

- Soil Spectroscopy
- Hyperspectral Remote Sensing
- Deep Learning
- Soil Property Prediction

## 目录说明

- `papers/`: 存放后续手动整理的论文文件或论文链接记录。
- `notes/`: 存放阅读过程中的零散笔记、问题、想法和术语解释。
- `summaries/`: 存放每篇论文的结构化阅读总结。
- `reading_plan/`: 存放文献阅读路线、阶段目标和每日任务。
- `research_map/`: 存放研究方向图谱、问题拆解和方法分类。

## 使用方式

1. 先阅读 `reading_plan/README.md`，明确一周阅读路线。
2. 再阅读 `research_map/research_tree.md`，建立领域整体框架。
3. 每读一篇论文，复制 `summaries/template.md` 作为该论文的总结模板。
4. 将临时想法、术语、疑问放入 `notes/`。
5. 每天结束时更新阅读收获、可复现方向和后续问题。

## 当前阶段重点

- 明确土壤属性预测任务的核心变量。
- 理解高光谱数据在土壤研究中的常见输入形式。
- 梳理传统机器学习与深度学习方法的差异。
- 找出最值得复现的 3-5 篇论文。
- 形成后续模型开发的技术判断依据。
